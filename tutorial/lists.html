Lists

Store multiple values in a single ordered collection.

A list is an ordered collection of values. Lists can hold any type of value — numbers, strings, booleans, other lists, or a mix of types.

Creating a list

 lists.ks
 numbers  = [1, 2, 3, 4, 5]
 fruits   = ["apple", "banana", "cherry"]
 mixed    = [1, "two", true, null]
 empty    = []

print(numbers)
print(fruits)
Output
[1, 2, 3, 4, 5]
["apple", "banana", "cherry"]

Accessing elements

Use square brackets with an index (starting at 0):

 index.ks
 fruits = ["apple", "banana", "cherry"]

print(fruits[0])   # apple
print(fruits[1])   # banana
print(fruits[2])   # cherry

# Negative indices count from the end
print(fruits[-1])  # cherry
print(fruits[-2])  # banana

Modifying elements

 modify.ks
 scores = [10, 20, 30]
scores[1] = 99
print(scores)   # [10, 99, 30]

Adding elements: push()

 push.ks
 items = ["a", "b"]
push(items, "c")
push(items, "d")
print(items)   # ["a", "b", "c", "d"]

Removing the last element: pop()

 pop.ks
 items = ["a", "b", "c"]
 last  = items.pop()
print(last)    # c
print(items)   # ["a", "b"]

List length

 len.ks
 fruits = ["apple", "banana", "cherry"]
print(len(fruits))   # 3

Iterating over a list

 iterate.ks
 numbers = [10, 20, 30, 40, 50]

for n in numbers {
    print(n * 2)
}
Output
20
40
60
80
100

List methods

Lists provide methods for searching and changing their contents:

 methods.ks
items = ["a", "b", "c"]
print(items.contains("b"))  # true
items.reverse()              # changes items in place
print(items)                  # ["c", "b", "a"]

What you learned

  • Create lists with [item1, item2, ...]
  • Access elements with list[index] (0-based)
  • Negative indices count from the end: list[-1]
  • push(list, item) or list.append(item) adds to the end; list.pop() removes and returns the last item
  • len(list) returns the number of elements
  • Use for x in list to iterate
  • Use list.contains(item) to check membership

Lists

Store multiple values in a single ordered collection.

A list is an ordered collection of values. Lists can hold any type of value — numbers, strings, booleans, other lists, or a mix of types.

Creating a list

 lists.ks
let numbers  = [1, 2, 3, 4, 5]
let fruits   = ["apple", "banana", "cherry"]
let mixed    = [1, "two", true, null]
let empty    = []

print(numbers)
print(fruits)
Output
[1, 2, 3, 4, 5]
["apple", "banana", "cherry"]

Accessing elements

Use square brackets with an index (starting at 0):

 index.ks
let fruits = ["apple", "banana", "cherry"]

print(fruits[0])   # apple
print(fruits[1])   # banana
print(fruits[2])   # cherry

# Negative indices count from the end
print(fruits[-1])  # cherry
print(fruits[-2])  # banana

Modifying elements

 modify.ks
let scores = [10, 20, 30]
scores[1] = 99
print(scores)   # [10, 99, 30]

Adding elements: push()

 push.ks
let items = ["a", "b"]
push(items, "c")
push(items, "d")
print(items)   # ["a", "b", "c", "d"]

Removing the last element: pop()

 pop.ks
let items = ["a", "b", "c"]
let last  = pop(items)
print(last)    # c
print(items)   # ["a", "b"]

List length

 len.ks
let fruits = ["apple", "banana", "cherry"]
print(len(fruits))   # 3

Iterating over a list

 iterate.ks
let numbers = [10, 20, 30, 40, 50]

for n in numbers {
    print(n * 2)
}
Output
20
40
60
80
100

Slicing

Extract a portion of a list with [start:end]:

 slice.ks
let nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])   # [1, 2, 3]
print(nums[3:])    # [3, 4, 5]
print(nums[:3])    # [0, 1, 2]

Checking membership

 in.ks
let fruits = ["apple", "banana", "cherry"]

if "banana" in fruits {
    print("banana is in the list!")
}

What you learned

  • Create lists with [item1, item2, ...]
  • Access elements with list[index] (0-based)
  • Negative indices count from the end: list[-1]
  • push(list, item) adds to the end; pop(list) removes from the end
  • len(list) returns the number of elements
  • Use for x in list to iterate
  • Use item in list to check membership

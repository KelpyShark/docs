Functions

Define reusable blocks of code that you can call by name.

A function is a named block of code that performs a specific task. You define it once and call it as many times as you need. Functions help you avoid repeating code and make programs easier to understand.

Defining a function

Use the def keyword, followed by the function name and parentheses:

def functionName(parameters) {
    code
}
 greet.ks
def greet() {
    print("Hello from the greet function!")
}

greet()    # call the function
greet()    # call it again
Output
Hello from the greet function!
Hello from the greet function!

Functions with parameters

Parameters allow you to pass values into a function when calling it:

 params.ks
def greet(name) {
    print("Hello, {$name}!")
}

greet("Alice")
greet("Bob")
greet("Charlie")
Output
Hello, Alice!
Hello, Bob!
Hello, Charlie!

Multiple parameters

 multi.ks
def introduce(name, age, city) {
    print("{$name} is {$age} years old and lives in {$city}.")
}

introduce("Alice", 30, "London")
introduce("Bob",   25, "Tokyo")
Output
Alice is 30 years old and lives in London.
Bob is 25 years old and lives in Tokyo.

Default parameter values

You can give parameters a default value that is used when no argument is provided:

 defaults.ks
def power(base, exponent = 2) {
    let result = 1
    for i in range(0, exponent) {
        result *= base
    }
    print(result)
}

power(3)      # uses default exponent=2  → 9
power(2, 10)  # exponent=10              → 1024
💡 Tip

Parameters with defaults must come after required parameters in the parameter list.

What you learned

  • Define functions with def name(params) { }
  • Call a function by writing its name followed by ()
  • Parameters are values passed into the function
  • Default parameter values are used when no argument is provided

Return Values

Make functions produce a result that you can use.

So far, our functions have printed things directly. But often you want a function to compute something and give that result back to the caller. Use the return keyword to send a value back.

Returning a value

 add.ks
def add(a, b) {
    return a + b
}

let sum = add(3, 7)
print(sum)         # 10
print(add(20, 5))  # 25

Using return values in expressions

 expressions.ks
def square(n) {
    return n * n
}

def cube(n) {
    return n * n * n
}

print(square(4) + cube(2))   # 16 + 8 = 24
print(square(square(3)))     # square(9) = 81

Early return

A function stops executing as soon as it hits a return statement. This is useful for early exit:

 early.ks
def is_even(n) {
    if n % 2 == 0 {
        return true
    }
    return false
}

print(is_even(4))    # true
print(is_even(7))    # false

Returning null

If a function has no return statement (or just return with no value), it returns null:

 null-return.ks
def say_hi() {
    print("Hi!")
}

let result = say_hi()   # prints "Hi!"
print(result)            # null

Practical example

 bmi.ks
def bmi(weight_kg, height_m) {
    return weight_kg / (height_m * height_m)
}

def bmi_category(bmi_value) {
    if bmi_value < 18.5 {
        return "Underweight"
    } elif bmi_value < 25 {
        return "Normal"
    } elif bmi_value < 30 {
        return "Overweight"
    } else {
        return "Obese"
    }
}

let my_bmi = bmi(70, 1.75)
print("BMI: {$my_bmi}")
print("Category: {$bmi_category(my_bmi)}")
Output
BMI: 22.857142857142858
Category: Normal

What you learned

  • Use return value to send a result back to the caller
  • Functions stop executing when they hit return
  • Return values can be used in expressions or stored in variables
  • Functions without a return return null

Hello, World!

Write and run your very first KelpyShark program.

The simplest program

In KelpyShark, printing text to the screen is done with the print function:

 hello.ks
print("Hello, World!")
Output
Hello, World!

That's it! One line — no imports, no boilerplate, no main function required.

Printing multiple values

You can print several items by calling print multiple times:

 greet.ks
print("Hello!")
print("Welcome to KelpyShark.")
print("Let's get started.")
Output
Hello!
Welcome to KelpyShark.
Let's get started.

Printing numbers and expressions

print can output any value — not just strings:

 numbers.ks
print(42)
print(3.14)
print(10 + 5)
print(100 / 4)
Output
42
3.14
15
25

How to run a KelpyShark file

Save your code in a file with the .ks extension, then run it with:

Terminal
kelpyshark run hello.ks
📝 Note

KelpyShark executes your file from top to bottom, line by line. There is no special entry point like main() needed for scripts.

What you learned

  • print() outputs values to the console
  • KelpyShark programs are just .ks text files
  • Run files with kelpyshark run filename.ks
  • No boilerplate is needed — code starts at the top of the file

Operators

Perform calculations, comparisons, and logical operations.

OperatorNameExampleResult

Assignment operators

Shorthand for updating a variable's value:

OperatorEquivalent toExample
+=x = x + nx += 5
-=x = x - nx -= 3
*=x = x * nx *= 2
/=x = x / nx /= 4
 assign.ks
let score = 100
score += 50
print(score)   # 150

score -= 20
print(score)   # 130

score *= 2
print(score)   # 260

String concatenation

The + operator also joins (concatenates) two strings:

 concat.ks
let first = "Kelpy"
let last  = "Shark"
print(first + last)   # KelpyShark

What you learned

  • Arithmetic operators: + - * / %
  • Comparison operators: == != < > <= >=
  • Logical operators: and or not
  • Assignment operators: += -= *= /=
  • + on strings does concatenation

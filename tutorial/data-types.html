Data Types

The fundamental kinds of values in KelpyShark.

KelpyShark is dynamically typed — you don't declare the type of a variable; KelpyShark figures it out from the value you assign. There are six built-in data types:

TypeExampleDescription
Number42, 3.14, -7Integer or decimal numbers
String"hello", 'world'Text in double or single quotes
Booleantrue, falseLogical true/false value
List[1, 2, 3]Ordered collection of values
Dictionary{"key": "value"}Key-value pairs
NullnullRepresents the absence of a value

Numbers

Numbers can be integers (whole numbers) or floats (decimal numbers). KelpyShark handles both with the same Number type.

 numbers.ks
let count    = 10       # integer
let price    = 4.99     # float
let negative = -3       # negative number
let big      = 1000000  # big integer

print(count + price)   # 14.99

Strings

Strings hold text. You can use either double quotes or single quotes.

 strings.ks
let greeting = "Hello, World!"
let language = 'KelpyShark'
print(greeting)
print(language)

Booleans

A boolean is either true or false. Booleans are used in conditions.

 booleans.ks
let is_sunny = true
let is_cold  = false

print(is_sunny)   # true
print(is_cold)    # false
print(10 > 5)     # true
print(3 == 7)     # false

Null

null represents "no value" — useful as a placeholder or to signal that something is missing.

 null.ks
let result = null
print(result)   # null

Checking the type of a value

The built-in type() function returns the type of any value as a string:

 typeof.ks
print(type(42))        # number
print(type("hello"))   # string
print(type(true))      # bool
print(type(null))      # null
print(type([1,2,3]))   # list
Output
number
string
bool
null
list

What you learned

  • KelpyShark has 6 built-in types: Number, String, Boolean, List, Dictionary, Null
  • You don't need to declare types — KelpyShark infers them
  • Use type(value) to inspect a value's type at runtime

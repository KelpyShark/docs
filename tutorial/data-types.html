Data Types

The fundamental kinds of values in KelpyShark.

KelpyShark is dynamically typed — you don't declare the type of a variable; its value determines the type at runtime. This lesson introduces six common kinds of values:

TypeExampleDescription
Number42, 3.14, -7Integer or decimal numbers
String"hello"Text in double quotes
Booleantrue, falseLogical true/false value
List[1, 2, 3]Ordered collection of values
Dictionary{"key": "value"}Key-value pairs
NullnullRepresents the absence of a value

Numbers

Numbers can be integers (whole numbers) or floats (decimal numbers). KelpyShark handles both with the same Number type.

 numbers.ks
 count    = 10       # integer
 price    = 4.99     # float
 negative = -3       # negative number
 big      = 1000000  # big integer

print(count + price)   # 14.99

Strings

Strings hold text and use double quotes. Escape a double quote with \".

 strings.ks
 greeting = "Hello, World!"
 language = "KelpyShark"
print(greeting)
print(language)

Booleans

A boolean is either true or false. Booleans are used in conditions.

 booleans.ks
 is_sunny = true
 is_cold  = false

print(is_sunny)   # true
print(is_cold)    # false
print(10 > 5)     # true
print(3 == 7)     # false

Null

null represents "no value" — useful as a placeholder or to signal that something is missing.

 null.ks
 result = null
print(result)   # null

Checking the type of a value

The built-in type() function returns a type name as a string. Numbers use the name "number"; dictionaries use "dict".

 typeof.ks
print(type(42))        # number
print(type("hello"))   # string
print(type(true))      # boolean
print(type(null))      # null
print(type([1, 2, 3])) # list
print(type({"x": 1}))  # dict
Output
number
string
boolean
null
list
dict

What you learned

  • Core values include numbers, strings, booleans, lists, dictionaries, and null
  • You don't need to declare types — KelpyShark infers them
  • Use type(value) to inspect a value's type at runtime

Standard Library

A tour of KelpyShark's built-in modules.

KelpyShark ships with a standard library (stdlib) — a collection of useful modules that are ready to import. You don't need to install anything extra; they're always available.

math

Mathematical functions and constants:

 stdlib-math.ks
import math

print(math.sqrt(25))       # 5
print(math.pow(2, 10))     # 1024
print(math.abs(-9))        # 9
print(math.floor(4.7))     # 4
print(math.ceil(4.1))      # 5
print(math.round(4.5))     # 5
print(math.min(3, 7))      # 3
print(math.max(3, 7))      # 7
print(math.pi)             # 3.141592653589793

strings

String manipulation beyond the built-in methods:

 stdlib-strings.ks
import strings

print(strings.upper("hello"))            # HELLO
print(strings.lower("WORLD"))            # world
print(strings.trim("  hi  "))            # hi
print(strings.replace("abc", "b", "X"))  # aXc
print(strings.split("a,b,c", ","))       # ["a", "b", "c"]
print(strings.join(["x", "y", "z"], "-"))# x-y-z
print(strings.starts_with("foo", "f"))   # true
print(strings.ends_with("bar", "r"))     # true
print(strings.contains("hello", "ell"))  # true

io

Read and write files:

 stdlib-io.ks
import io

# Write a file
io.write_file("notes.txt", "Hello from KelpyShark!")

# Read it back
content = io.read_file("notes.txt")
print(content)            # Hello from KelpyShark!

# Append to a file
io.append_file("notes.txt", "\nSecond line")

# Check if a file exists
print(io.file_exists("notes.txt"))    # true

json

Parse JSON strings and convert values back to JSON:

 stdlib-json.ks
import json

raw = "{\"name\":\"Alice\",\"age\":30}"
data = json.decode(raw)
print(data["name"])         # Alice
print(data["age"])          # 30

 obj = {"x": 1, "y": 2}
 text = json.encode(obj)
print(text)                 # {"x":1,"y":2}

sys

Information about the running environment:

 stdlib-sys.ks
import sys

print(sys.platform())       # operating system name
print(sys.cwd())            # current working directory

 args = sys.args()         # arguments passed after `--` to `run`
sys.exit(0)                 # exit with a status code

http

Make HTTP requests to APIs and websites:

 stdlib-http.ks
import http
import json

# GET request
 body = http.get("https://api.example.com/users/1")
user = json.decode(body)
print(user["name"])

# POST request
 payload = json.encode({"title": "New post", "body": "Hello!"})
post_res = http.post_json("https://api.example.com/posts", payload)
Tip — The full API for every module is documented in the Reference section. Head there when you need to look up a specific function.

What you learned

  • math — sqrt, pow, floor, ceil, round, min, max, pi
  • strings — upper, lower, trim, replace, split, join, contains…
  • io — read, write, append, exists
  • json — parse, stringify
  • sys — environment variables, arguments, clock, sleep, working directory, platform, and exit
  • http — GET, POST, JSON POST, and GET status requests

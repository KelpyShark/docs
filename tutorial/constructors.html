Constructors

Initialize objects when they're created.

A constructor is a special method that runs automatically when you create a new instance of a class. In KelpyShark, the constructor is named __init__.

The __init__ method

 constructor.ks
class BankAccount {
    def __init__(self, owner, initial_balance) {
        self.owner   = owner
        self.balance = initial_balance
        print("Account created for {$owner} with ${$initial_balance}")
    }
}

 acc = new BankAccount("Alice", 500)
Output
Account created for Alice with $500

Constructor parameters

Constructors use ordinary function parameters, so each argument must be supplied:

 defaults.ks
class Player {
    def __init__(self, name, health, score) {
        self.name   = name
        self.health = health
        self.score  = score
    }

    def status(self) {
        print("{$self.name} | HP: {$self.health} | Score: {$self.score}")
    }
}

 p1 = new Player("Alice", 100, 0)
 p2 = new Player("Bob", 80, 250)

p1.status()
p2.status()
Output
Alice | HP: 100 | Score: 0
Bob | HP: 80 | Score: 250

Constructor validation

Constructors are a great place to validate input:

 validate.ks
class Temperature {
    def __init__(self, celsius) {
        if celsius < -273.15 {
            throw "Temperature below absolute zero is not possible."
        }
        self.celsius = celsius
    }

    def to_fahrenheit(self) {
        return self.celsius * 9 / 5 + 32
    }
}

 t = new Temperature(100)
print(t.to_fahrenheit())   # 212
Tip

If your class needs no initialization, you can omit the constructor entirely and KelpyShark will still let you create instances with new ClassName().

What you learned

  • The constructor is def __init__(self, ...) { }
  • It runs automatically when you write new ClassName(...)
  • Use it to initialize attributes and validate inputs
  • Constructor calls provide every declared parameter

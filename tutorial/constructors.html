Constructors

Initialize objects when they're created.

A constructor is a special method that runs automatically when you create a new instance of a class. In KelpyShark, the constructor is always named new.

The new method

 constructor.ks
class BankAccount {
    def new(owner, initial_balance) {
        self.owner   = owner
        self.balance = initial_balance
        print("Account created for {$owner} with ${$initial_balance}")
    }
}

let acc = new BankAccount("Alice", 500)
Output
Account created for Alice with $500

Constructor with default values

 defaults.ks
class Player {
    def new(name, health = 100, score = 0) {
        self.name   = name
        self.health = health
        self.score  = score
    }

    def status() {
        print("{$self.name} | HP: {$self.health} | Score: {$self.score}")
    }
}

let p1 = new Player("Alice")
let p2 = new Player("Bob", 80, 250)

p1.status()
p2.status()
Output
Alice | HP: 100 | Score: 0
Bob | HP: 80 | Score: 250

Constructor validation

Constructors are a great place to validate input:

 validate.ks
class Temperature {
    def new(celsius) {
        if celsius < -273.15 {
            throw "Temperature below absolute zero is not possible."
        }
        self.celsius = celsius
    }

    def to_fahrenheit() {
        return self.celsius * 9 / 5 + 32
    }
}

let t = new Temperature(100)
print(t.to_fahrenheit())   # 212
💡 Tip

If your class needs no initialization, you can omit the constructor entirely and KelpyShark will still let you create instances with new ClassName().

What you learned

  • The constructor is def new(...) { }
  • It runs automatically when you write new ClassName(...)
  • Use it to initialize attributes and validate inputs
  • Constructor parameters can have default values

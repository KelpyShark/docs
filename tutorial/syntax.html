Syntax Overview

Learn the fundamental rules and structure of KelpyShark code.

Statements and lines

Each statement in KelpyShark is written on its own line. Unlike some languages, there are no semicolons required at the end of lines.

 example.ks
let name = "Alice"
let age  = 30
print(name)
print(age)

Blocks and indentation

Code blocks (inside if, while, def, class, etc.) are enclosed in curly braces { }. Indentation is optional but strongly recommended for readability.

 blocks.ks
if age > 18 {
    print("Adult")
} else {
    print("Minor")
}

def greet(name) {
    print("Hello, {$name}!")
}

Case sensitivity

KelpyShark is case-sensitive. name, Name, and NAME are three different variables.

Identifiers

Variable names, function names, and class names are called identifiers. They must:

  • Start with a letter (a–z, A–Z) or an underscore (_)
  • Contain only letters, digits (0–9), or underscores
  • Not be a reserved keyword
 identifiers.ks
let myVariable = 10      # ✓ valid
let _private   = true    # ✓ valid
let user2      = "Bob"   # ✓ valid

# let 2user = 0          # ✗ cannot start with digit
# let my-var = 0         # ✗ hyphens not allowed

Keywords

The following words are reserved and cannot be used as identifiers:

Reserved keywords
def  if  elif  else  while  for  in  return
import  true  false  and  or  not  break
continue  try  catch  throw  class  null  new  self  static  print

Whitespace

Spaces and blank lines between statements are ignored by the interpreter. Use them freely to make your code easier to read.

💡 Convention

KelpyShark code conventionally uses 4-space indentation inside blocks, and snake_case for variable and function names.

What you learned

  • Statements are written one per line — no semicolons
  • Blocks use curly braces { }
  • KelpyShark is case-sensitive
  • Identifiers start with a letter or underscore
  • Reserved keywords cannot be used as names

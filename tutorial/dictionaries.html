Dictionaries

Store data as key-value pairs.

A dictionary (also called a map or hash map in other languages) stores data as key-value pairs. Unlike lists which use numeric indices, dictionaries let you use descriptive string keys to look up values.

Creating a dictionary

 dict.ks
let person = {
    "name": "Alice",
    "age":  30,
    "city": "London"
}

print(person)
Output
{"name": "Alice", "age": 30, "city": "London"}

Accessing values

Use square bracket notation with the key name:

 access.ks
let person = {"name": "Alice", "age": 30}

print(person["name"])   # Alice
print(person["age"])    # 30

Adding and updating entries

 update.ks
let config = {"debug": false, "version": 1}

# Update an existing key
config["version"] = 2

# Add a new key
config["author"] = "Alice"

print(config)
Output
{"debug": false, "version": 2, "author": "Alice"}

Checking for a key

 contains.ks
let settings = {"theme": "dark", "lang": "en"}

if "theme" in settings {
    print("Theme is set to: {$settings["theme"]}")
}

Iterating over a dictionary

Use for key in dict to loop over keys:

 iterate.ks
let scores = {"Alice": 95, "Bob": 87, "Charlie": 72}

for name in scores {
    print("{$name}: {$scores[name]}")
}
Output
Alice: 95
Bob: 87
Charlie: 72

Nested dictionaries

Dictionary values can themselves be dictionaries:

 nested.ks
let user = {
    "name": "Alice",
    "address": {
        "city":    "London",
        "country": "UK"
    }
}

print(user["address"]["city"])   # London

What you learned

  • Dictionaries store key-value pairs: {"key": value}
  • Access values with dict["key"]
  • Add or update with dict["key"] = value
  • Check membership with "key" in dict
  • Iterate over keys with for key in dict
  • Values can be any type, including other dictionaries

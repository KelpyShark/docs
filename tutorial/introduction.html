Introduction to KelpyShark

Learn how the tutorial works and what you will build as you go.

What is KelpyShark?

KelpyShark is a dynamically typed programming language with a small set of readable building blocks: values, functions, conditions, loops, lists, dictionaries, and classes. You can run a .ks program directly with its interpreter.

The build command can also generate C, JavaScript, Java, or C# source for supported parts of the language. Generated source is not an executable, and each target supports a different subset. The interpreter is the recommended way to run the examples in this tutorial.

What can KelpyShark do?

  • Automate repetitive tasks and write scripts
  • Build command-line tools and utilities
  • Work with files, JSON, and HTTP APIs through standard-library modules
  • Model real-world data with classes and objects
  • Use the command-line tool to create projects and manage packages

Why KelpyShark?

Easy to learn

The syntax is intentionally minimal. If you've never programmed before, KelpyShark is a great first language.

Batteries included

Import the registered math, strings, io, json, sys, and http modules.

A taste of KelpyShark

Here's a short program that shows off a few features of the language:

 example.ks
# A simple KelpyShark program

def greet(name) {
    print("Hello, {$name}! Welcome to KelpyShark.")
}

class Animal {
    def __init__(self, name, sound) {
        self.name = name
        self.sound = sound
    }

    def speak(self) {
        print("{$self.name} says {$self.sound}!")
    }
}

greet("World")

 dog = new Animal("Rex", "woof")
dog.speak()

for i in range(1, 4) {
    print("Count: {$i}")
}
Output
Hello, World! Welcome to KelpyShark.
Rex says woof!
Count: 1
Count: 2
Count: 3

Don't worry if you don't understand all of it yet — this tutorial will explain every part step by step.

How to use this tutorial

Each lesson introduces one idea, shows a KelpyShark example, and explains what the program prints. At the end, try the practice prompts in your own .ks file. Run your file with kelpyshark run filename.ks.

Tip

Follow the sidebar from top to bottom if this is your first programming language. If you already know the basics, choose a topic and use the reference pages for exact syntax.

In this tutorial you will learn

  • Variables, data types, and operators
  • Strings and string methods
  • Control flow: if/else, while, for
  • Functions and return values
  • Lists and dictionaries
  • Classes and object-oriented programming
  • Error handling with try/catch
  • Importing modules and using the standard library

Scope

Understanding where variables live and can be accessed.

Scope determines where a variable is accessible. Function parameters and new variables created inside a function are local. A function can read outer variables, and assignment to an existing outer name updates that binding.

Local scope

Variables declared inside a function are local — they only exist while the function runs, and cannot be accessed outside it:

 local.ks
def my_function() {
     local_var = "I'm local"
    print(local_var)
}

my_function()

# This would error — local_var doesn't exist here:
# print(local_var)

Global scope

Variables declared at the top level (outside any function) are global and can be read from inside functions:

 global.ks
 greeting = "Hello"   # global variable

def say_hi(name) {
    print("{$greeting}, {$name}!")   # can read global
}

say_hi("Alice")   # Hello, Alice!

Updating an outer variable

When an outer variable already exists, assignment inside a function updates it. Use a distinct name for a local value:

 shadow.ks
 value = "global"

def test() {
    value = value + " updated"
    local_value = "local"
    print(local_value)
}

test()
print(value)               # global updated
Output
local
global updated
💡 Best practice

Minimize your use of global variables. Pass data into functions as parameters and get results back via return. This makes functions independent and reusable.

What you learned

  • Local variables only exist inside the function they're declared in
  • Global variables are accessible everywhere
  • Assignment updates the nearest existing outer binding; new names are local to the function
  • Prefer passing data via parameters over using globals

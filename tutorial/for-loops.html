For Loops

Iterate over a sequence of values.

The for loop is the most common way to repeat code in KelpyShark. It iterates over any sequence — a list, a string, or a range of numbers.

Looping over a range

Use range(start, end) to produce a sequence of numbers. The range includes start but excludes end:

for variable in range(start, end) {
    code
}
 range.ks
for i in range(1, 6) {
    print(i)
}
Output
1
2
3
4
5

Looping over a list

 list.ks
let fruits = ["apple", "banana", "cherry"]

for fruit in fruits {
    print("I like {$fruit}")
}
Output
I like apple
I like banana
I like cherry

Looping over a string

A for loop over a string visits each character:

 string.ks
for ch in "hello" {
    print(ch)
}
Output
h
e
l
l
o

Practical example: sum of a list

 sum.ks
let numbers = [10, 20, 30, 40, 50]
let total   = 0

for n in numbers {
    total += n
}

print("Total: {$total}")   # Total: 150

FizzBuzz example

 fizzbuzz.ks
for i in range(1, 21) {
    if i % 15 == 0 {
        print("FizzBuzz")
    } elif i % 3 == 0 {
        print("Fizz")
    } elif i % 5 == 0 {
        print("Buzz")
    } else {
        print(i)
    }
}
💡 Tip

Use for when you know the sequence you're iterating over. Use while when you need to loop until an unknown condition is met.

What you learned

  • for x in sequence { } iterates over any sequence
  • range(start, end) creates a number sequence (end is exclusive)
  • Works with lists, strings, and ranges
  • The loop variable holds the current item on each iteration

String Methods

Built-in operations you can perform on strings.

Strings in KelpyShark come with a set of built-in methods. You call them with dot notation: myString.methodName(). Because strings are immutable, methods always return a new string.

Case conversion

 case.ks
let s = "Hello, World!"

print(s.upper())   # HELLO, WORLD!
print(s.lower())   # hello, world!

Trimming whitespace

 trim.ks
let s = "   hello   "
print(s.trim())   # "hello"

Checking content

 check.ks
let s = "KelpyShark"

print(s.starts_with("Kelpy"))   # true
print(s.ends_with("Shark"))     # true
print(s.contains("py"))         # true
print(s.contains("xyz"))        # false

Splitting and joining

 split.ks
let csv = "one,two,three"
let parts = csv.split(",")
print(parts)       # ["one", "two", "three"]
print(parts[1])    # two

let joined = parts.join(" | ")
print(joined)      # one | two | three

Replacing substrings

 replace.ks
let s = "I like cats and cats like me"
print(s.replace("cats", "dogs"))
# I like dogs and dogs like me

Finding substrings

 find.ks
let s = "hello world"
print(s.index_of("world"))   # 6
print(s.index_of("xyz"))     # -1  (not found)

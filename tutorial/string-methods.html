String Methods

Built-in operations you can perform on strings.

Strings in KelpyShark come with a set of built-in methods. You call them with dot notation: myString.methodName(). Because strings are immutable, methods always return a new string.

Case conversion

 case.ks
 s = "Hello, World!"

print(s.upper())   # HELLO, WORLD!
print(s.lower())   # hello, world!

Trimming whitespace

 trim.ks
 s = "   hello   "
print(s.trim())   # "hello"

Checking content

 check.ks
 s = "KelpyShark"

print(s.starts_with("Kelpy"))   # true
print(s.ends_with("Shark"))     # true
print(s.contains("py"))         # true
print(s.contains("xyz"))        # false

Splitting and joining

 split.ks
 csv = "one,two,three"
 parts = csv.split(",")
print(parts)       # ["one", "two", "three"]
print(parts[1])    # two

 joined = parts.join(" | ")
print(joined)      # one | two | three

Replacing substrings

 replace.ks
 s = "I like cats and cats like me"
print(s.replace("cats", "dogs"))
# I like dogs and dogs like me

Character access and substrings

 find.ks
 s = "hello world"
print(s.char_at(6))          # w
print(s.substring(0, 5))     # hello

Quick reference

MethodReturnsDescription
.upper()StringAll uppercase
.lower()StringAll lowercase
.trim()StringRemove leading/trailing whitespace
.starts_with(s)BooleanDoes the string start with s?
.ends_with(s)BooleanDoes the string end with s?
.contains(s)BooleanDoes the string contain s?
.replace(old, new)StringReplace all occurrences
.split(delim)ListSplit into a list of substrings
.char_at(i)StringCharacter at the zero-based index i
.substring(start, end)StringCharacters from start up to, but not including, end
.reverse()StringCharacters in reverse order
.to_num()NumberParse the string as a number

What you learned

  • String methods return useful values such as trimmed or uppercase text
  • split turns a string into a list; join combines a list into a string
  • See the reference for the full list of supported string methods

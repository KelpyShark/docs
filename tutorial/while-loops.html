While Loops

Repeat a block of code as long as a condition is true.

Basic while loop

A while loop keeps running its body as long as the condition evaluates to true:

while condition {
    code to repeat
}
 while.ks
let count = 1

while count <= 5 {
    print(count)
    count += 1
}
Output
1
2
3
4
5

Counting down

 countdown.ks
let n = 5

while n > 0 {
    print("{$n}...")
    n -= 1
}
print("Liftoff!")
Output
5...
4...
3...
2...
1...
Liftoff!

Loops with break

Use break to exit a loop early:

 break.ks
let i = 0

while true {
    if i == 5 {
        break
    }
    print(i)
    i += 1
}
Output
0
1
2
3
4
⚠️ Infinite loops

If the condition never becomes false and you don't use break, the loop will run forever. Always make sure your loop has a way to end.

Practical example: input validation

 validate.ks
# Sum numbers from 1 to 10 using a while loop
let sum = 0
let i   = 1

while i <= 10 {
    sum += i
    i   += 1
}

print("Sum 1–10 = {$sum}")   # Sum 1–10 = 55

What you learned

  • while condition { } repeats while the condition is true
  • Update the loop variable inside the body to avoid infinite loops
  • break exits the loop immediately
  • while true { } with a break is a common pattern

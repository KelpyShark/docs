Attributes

Store data on objects using instance attributes.

Attributes are variables that belong to an object. They store the data (state) that describes that object. In KelpyShark, you set attributes on an object using self.attributeName.

Setting attributes in the constructor

The most common place to set attributes is in the constructor (def new):

 attributes.ks
class Circle {
    def new(radius) {
        self.radius = radius
        self.pi     = 3.14159
    }

    def area() {
        return self.pi * self.radius * self.radius
    }

    def perimeter() {
        return 2 * self.pi * self.radius
    }
}

let c = new Circle(5)
print(c.radius)          # 5
print(c.area())          # 78.53975
print(c.perimeter())     # 31.4159

Accessing attributes from outside

Attributes are accessible from outside the class using dot notation:

 access.ks
class Person {
    def new(name, age) {
        self.name = name
        self.age  = age
    }
}

let alice = new Person("Alice", 30)
print(alice.name)   # Alice
print(alice.age)    # 30

# You can also modify attributes from outside:
alice.age = 31
print(alice.age)    # 31

Attributes set dynamically

You can set new attributes on an object at any time, even outside the constructor:

 dynamic.ks
class Box {}

let b = new Box()
b.width  = 10
b.height = 5
print("{$b.width} x {$b.height}")

Each instance has its own attributes

Changing one object's attributes does not affect another:

 independent.ks
class Counter {
    def new() {
        self.count = 0
    }
    def increment() {
        self.count += 1
    }
}

let a = new Counter()
let b = new Counter()

a.increment()
a.increment()
b.increment()

print(a.count)   # 2
print(b.count)   # 1  — independent!

What you learned

  • Attributes store data on an object instance
  • Set them with self.attrName = value
  • Access them from outside with obj.attrName
  • Each instance has its own independent copy of attributes

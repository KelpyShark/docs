Comments

Write notes in your code that the interpreter ignores.

Single-line comments

A comment starts with a # character. Everything after it on the same line is ignored by KelpyShark.

 comments.ks
# This is a comment — the interpreter ignores it
print("Hello!")  # This comment is at the end of a line

# Comments are useful for explaining what your code does:
let speed = 60   # speed in km/h

Multi-line comments

KelpyShark does not have a dedicated multi-line comment syntax. Simply use multiple # lines:

 multiline.ks
# This function calculates the area of a rectangle.
# Arguments:
#   width  - the width of the rectangle
#   height - the height of the rectangle
# Returns:
#   the area as a number
def area(width, height) {
    return width * height
}

Commenting out code

You can temporarily disable code by putting a # in front of it. This is called "commenting out":

 debug.ks
let x = 10
# print("debug: x =", x)   # disabled for now
print("x is", x)
💡 Good practice

Write comments that explain why you did something, not just what the code does. The code already shows what — good comments add context.

What you learned

  • Use # to write a comment
  • Everything after # on that line is ignored
  • Stack multiple # lines for multi-line comments
  • Commenting out is useful for debugging

If / Elif / Else

Run different code depending on conditions.

Basic if statement

The if statement runs a block of code only if a condition is true:

if condition {
    code to run
}
 if.ks
let temperature = 30

if temperature > 25 {
    print("It's hot outside!")
}
Output
It's hot outside!

If / else

The else block runs when the condition is false:

 if-else.ks
let age = 16

if age >= 18 {
    print("You can vote.")
} else {
    print("You are too young to vote.")
}
Output
You are too young to vote.

Elif — multiple conditions

Use elif (short for "else if") to check multiple conditions in sequence:

 elif.ks
let score = 75

if score >= 90 {
    print("Grade: A")
} elif score >= 80 {
    print("Grade: B")
} elif score >= 70 {
    print("Grade: C")
} elif score >= 60 {
    print("Grade: D")
} else {
    print("Grade: F")
}
Output
Grade: C
📝 Note

Only the first matching branch runs. Once KelpyShark finds a true condition, it skips all remaining elif and else branches.

Nested if statements

You can place if statements inside other if statements:

 nested.ks
let is_member = true
let age = 20

if is_member {
    if age >= 18 {
        print("Welcome, adult member!")
    } else {
        print("Welcome, junior member!")
    }
} else {
    print("Please sign up first.")
}

Conditions with logical operators

 logical.ks
let x = 15

if x > 10 and x < 20 {
    print("x is between 10 and 20")
}

if x == 0 or x == 15 {
    print("x is 0 or 15")
}

if not (x == 0) {
    print("x is not zero")
}

What you learned

  • if condition { } — runs if condition is true
  • else { } — runs if the condition is false
  • elif condition { } — checks an additional condition
  • Only the first matching branch executes
  • Conditions can use and, or, not

Introduction to Classes

Model real-world things with object-oriented programming.

A class is a blueprint for creating objects. Each object (called an instance) created from a class gets its own copy of the class's attributes (data) and methods (functions).

Object-oriented programming (OOP) helps you organize code around real-world concepts — a Car, a User, a BankAccount — rather than just procedures.

Defining a class

class ClassName {
    attributes and methods
}
 dog.ks
class Dog {
    def __init__(self, name, breed) {
        self.name  = name
        self.breed = breed
    }

    def bark(self) {
        print("{$self.name} says: Woof!")
    }

    def describe(self) {
        print("{$self.name} is a {$self.breed}.")
    }
}

 rex  = new Dog("Rex", "German Shepherd")
 luna = new Dog("Luna", "Labrador")

rex.bark()
luna.describe()
rex.describe()
Output
Rex says: Woof!
Luna is a Labrador.
Rex is a German Shepherd.

Key concepts

  • class — keyword to define a new class
  • def __init__(self, ...) — the constructor, called when creating an instance
  • self — refers to the current object instance
  • self.name = ... — stores an attribute on the object
  • new ClassName(...) — creates a new instance of the class
  • object.method() — calls a method on an object
📝 Note

In KelpyShark, new creates an instance (new Dog("Rex", "Lab")); the constructor method is named __init__.

What you learned

  • A class is a blueprint for creating objects
  • Define classes with class Name { }
  • The constructor is def __init__(self, ...) { }
  • self refers to the current instance
  • Create instances with new ClassName(...)
  • Call methods with instance.method()

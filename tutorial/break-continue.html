Break & Continue

Control the flow inside loops.

break — exit the loop

break immediately exits the innermost loop, regardless of whether the condition is still true.

 break.ks
# Find the first number divisible by 7
for i in range(1, 100) {
    if i % 7 == 0 {
        print("First multiple of 7: {$i}")
        break
    }
}
Output
First multiple of 7: 7

continue — skip to next iteration

continue skips the rest of the current loop iteration and moves straight to the next one.

 continue.ks
# Print only odd numbers from 1 to 10
for i in range(1, 11) {
    if i % 2 == 0 {
        continue    # skip even numbers
    }
    print(i)
}
Output
1
3
5
7
9

Using break and continue together

 combined.ks
let items = [3, 7, -1, 12, 5, -8, 9]

for item in items {
    if item < 0 {
        print("Found negative — stopping!")
        break
    }
    if item == 7 {
        continue    # skip 7
    }
    print(item)
}
Output
3
12
Found negative — stopping!
📝 Note

break and continue only affect the innermost loop. In nested loops, they do not affect outer loops.

What you learned

  • break immediately exits the loop
  • continue skips the rest of the current iteration
  • Both work in for and while loops
  • They only affect the innermost loop in nested structures

Type Casting

Convert values from one type to another.

Sometimes you need to convert a value from one type to another — for example, turning a number into a string to print it alongside text, or turning a string into a number to do arithmetic. This is called type casting.

Converting to a string: str()

Use str() to convert any value to a string:

 tostr.ks
let age = 30
let message = "I am " + str(age) + " years old."
print(message)

print(str(3.14))   # "3.14"
print(str(true))   # "true"
print(str(null))   # "null"
Output
I am 30 years old.
3.14
true
null

Converting to a number: num()

Use num() to parse a string as a number:

 tonum.ks
let text   = "42"
let number = num(text)
print(number + 8)    # 50

let pi = num("3.14")
print(pi * 2)        # 6.28
Output
50
6.28
⚠️ Caution

If you pass a non-numeric string to num(), it will throw a runtime error. Make sure the string actually contains a valid number.

Implicit conversion

KelpyShark does not implicitly convert types for you. You must be explicit:

 explicit.ks
let n = 10

# This will error — cannot add number + string:
# print(n + " items")

# This works — explicitly convert:
print(str(n) + " items")   # "10 items"

# Or use string interpolation (easiest!):
print("{$n} items")        # "10 items"
💡 Tip

String interpolation ("{$variable}") is usually cleaner than calling str() manually. Learn more on the String Formatting page.

What you learned

  • str(value) converts any value to a string
  • num(value) parses a string as a number
  • KelpyShark does not implicitly convert types — you must be explicit
  • String interpolation is often the easiest alternative

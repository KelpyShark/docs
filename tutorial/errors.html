Error Handling

Handle mistakes gracefully with try and catch.

Errors happen — files don't exist, numbers get divided by zero, invalid input arrives. KelpyShark lets you catch these errors so your program can respond sensibly instead of crashing.

try / catch

Wrap risky code in a try block. If an error occurs, execution jumps to the catch block:

 errors.ks
try {
    let x = 10 / 0
    print("Result: {$x}")
} catch (e) {
    print("Caught an error: {$e}")
}
Output
Caught an error: Division by zero

Catching specific errors

The variable after catch holds the error message. You can inspect it to decide how to respond:

 inspect-error.ks
def safe_divide(a, b) {
    try {
        return a / b
    } catch (e) {
        print("Error: {$e}")
        return null
    }
}

let result = safe_divide(10, 2)
print(result)       # 5

let bad = safe_divide(10, 0)
print(bad)          # null
Output
5
Error: Division by zero
null

Recovering from errors

Use try / catch to keep your program running even when something goes wrong:

 recovery.ks
let items = ["10", "abc", "30", "xyz", "50"]
let total = 0

for item in items {
    try {
        total += num(item)
    } catch (e) {
        print("Skipping '{$item}' — not a number")
    }
}

print("Total: {$total}")
Output
Skipping 'abc' — not a number
Skipping 'xyz' — not a number
Total: 90
Note — Code after the error inside a try block is skipped. Execution resumes from the start of the catch block.

Nested try / catch

You can nest error handlers for different levels of risk:

 nested.ks
def load_config(path) {
    try {
        let data = io.read(path)
        try {
            return json.parse(data)
        } catch (e) {
            print("Config is not valid JSON: {$e}")
            return null
        }
    } catch (e) {
        print("Could not open file: {$e}")
        return null
    }
}

What you learned

  • try { } wraps code that might fail
  • catch (e) { } runs when an error occurs — e holds the message
  • After the catch block, the program continues normally
  • You can nest try / catch blocks for fine-grained control

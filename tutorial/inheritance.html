Inheritance

Build new classes on top of existing ones.

Inheritance and super are not implemented in the current language. Class declarations contain methods but cannot name a parent class. Use composition: store another object in a field and call its methods.

Composition example

 composition.ks
class Engine {
    def start(self) {
        print("Engine started")
    }
}

class Car {
    def __init__(self, engine) {
        self.engine = engine
    }

    def start(self) {
        self.engine.start()
    }
}

car = new Car(new Engine())
car.start()
Output
Engine started

What you learned

  • KelpyShark does not currently support class inheritance or super
  • Composition lets one object store another object and call its methods

Try it yourself

Write these steps in practice.ks, then run the file with kelpyshark run practice.ks.

  1. Create an Engine class with a start() method.
  2. Store an engine inside a Car object and call the engine through the car.

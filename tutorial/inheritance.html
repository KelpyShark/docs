Inheritance

Build new classes on top of existing ones.

Inheritance lets a class extend another class, inheriting all its attributes and methods while adding or overriding behaviour.

Extending a class

Use class Child(Parent) syntax:

 inherit.ks
class Animal {
    def new(name) {
        self.name = name
    }

    def speak() {
        print("{$self.name} makes a sound.")
    }
}

class Dog(Animal) {
    def fetch(item) {
        print("{$self.name} fetches the {$item}!")
    }
}

let d = new Dog("Rex")
d.speak()       # inherited
d.fetch("ball")
Output
Rex makes a sound.
Rex fetches the ball!

Calling the parent constructor

When the child has its own constructor, call the parent's constructor with super(args) to initialise inherited attributes:

 super.ks
class Vehicle {
    def new(make, model) {
        self.make  = make
        self.model = model
    }

    def describe() {
        print("{$self.make} {$self.model}")
    }
}

class Car(Vehicle) {
    def new(make, model, doors) {
        super(make, model)
        self.doors = doors
    }

    def describe() {
        print("{$self.make} {$self.model} ({$self.doors} doors)")
    }
}

let c = new Car("Toyota", "Corolla", 4)
c.describe()
Output
Toyota Corolla (4 doors)

Overriding methods

A child class can replace a parent method by defining one with the same name:

 override.ks
class Shape {
    def area() {
        return 0
    }

    def describe() {
        print("Area = {$self.area()}")
    }
}

class Circle(Shape) {
    def new(radius) {
        self.radius = radius
    }

    def area() {
        return 3.14159 * self.radius * self.radius
    }
}

class Square(Shape) {
    def new(side) {
        self.side = side
    }

    def area() {
        return self.side * self.side
    }
}

let c = new Circle(5)
c.describe()

let s = new Square(4)
s.describe()
Output
Area = 78.53975
Area = 16
Tip — Inheritance promotes code reuse. Put shared logic in the parent class so every child class benefits from it automatically.

What you learned

  • class Child(Parent) makes Child inherit everything from Parent
  • Use super(args) to call the parent constructor
  • Override a parent method by defining one with the same name in the child
  • Inherited methods still work as expected on child instances

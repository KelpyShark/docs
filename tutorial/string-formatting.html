String Formatting

Embed variables and expressions inside strings with interpolation.

String interpolation

KelpyShark supports string interpolation — embedding variable values directly inside a string using the {$variable} syntax. This is much cleaner than manual string concatenation with +.

"text {$variable} more text"
 interpolation.ks
let name = "Alice"
let age  = 30

# Without interpolation — awkward:
print("Hello, " + name + "! You are " + str(age) + " years old.")

# With interpolation — clean and readable:
print("Hello, {$name}! You are {$age} years old.")
Output
Hello, Alice! You are 30 years old.
Hello, Alice! You are 30 years old.

Interpolating expressions

You can place any expression inside {$ } — not just variable names:

 expr.ks
let price    = 9.99
let quantity = 3

print("Total: {$price * quantity}")          # Total: 29.97
print("Double the price: {$price * 2}")      # Double the price: 19.98

let items = ["apple", "banana", "cherry"]
print("First item: {$items[0]}")             # First item: apple
print("Count: {$len(items)} items")          # Count: 3 items

Interpolation in function calls

 greet.ks
def welcome(user, score) {
    print("Welcome, {$user}! Your score is {$score}/100.")
}

welcome("Bob", 87)
Output
Welcome, Bob! Your score is 87/100.
💡 Best practice

Prefer "{$variable}" interpolation over string concatenation with +. It's shorter, more readable, and handles automatic type conversion.

What you learned

  • Use {$varName} inside a string to embed a variable's value
  • Any expression works inside {$ }
  • Interpolation automatically converts values to strings
  • It's cleaner than string concatenation with +

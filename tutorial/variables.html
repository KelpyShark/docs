Variables

Store and reuse values in your programs.

Creating a variable

A variable is a named value. Create or update one with an assignment: write its name, an equals sign, and the value. KelpyShark does not use a declaration keyword.

name = value
 variables.ks
 name = "Alice"
 age  = 25
 height = 1.72
 is_student = true

print(name)
print(age)
print(height)
print(is_student)
Output
Alice
25
1.72
true

Changing a variable's value

Variables are mutable and can be reassigned at any time:

 reassign.ks
 score = 0
print(score)   # 0

score = 10
print(score)   # 10

score = score + 5
print(score)   # 15
Output
0
10
15

Multiple assignments

You can declare multiple variables one after another:

 multi.ks
 x = 1
 y = 2
 z = x + y
print(z)   # 3

Naming conventions

KelpyShark conventionally uses snake_case for variable names:

 naming.ks
 first_name = "Alice"
 last_name  = "Smith"
 full_name  = first_name + " " + last_name
print(full_name)   # Alice Smith
Caution

Using a variable before assigning it will cause a runtime error. Always assign a value before reading it.

What you learned

  • Use name = value to create or update a variable
  • Variable names use snake_case by convention
  • Variables can hold strings, numbers, booleans, and more

  2. Change the age and print it again.

Variables

Store and reuse values in your programs.

Creating a variable

A variable is a named container for a value. In KelpyShark, you create a variable with the let keyword, followed by a name, an equals sign, and the value.

let name = value
 variables.ks
let name = "Alice"
let age  = 25
let height = 1.72
let is_student = true

print(name)
print(age)
print(height)
print(is_student)
Output
Alice
25
1.72
true

Changing a variable's value

Variables are mutable — you can reassign them at any time (without let):

 reassign.ks
let score = 0
print(score)   # 0

score = 10
print(score)   # 10

score = score + 5
print(score)   # 15
Output
0
10
15

Multiple assignments

You can declare multiple variables one after another:

 multi.ks
let x = 1
let y = 2
let z = x + y
print(z)   # 3

Naming conventions

KelpyShark conventionally uses snake_case for variable names:

 naming.ks
let first_name = "Alice"
let last_name  = "Smith"
let full_name  = first_name + " " + last_name
print(full_name)   # Alice Smith
⚠️ Caution

Using a variable before assigning it will cause a runtime error. Always assign a value before reading it.

What you learned

  • Use let name = value to create a variable
  • Variables can be reassigned without let
  • Variable names use snake_case by convention
  • Variables can hold strings, numbers, booleans, and more

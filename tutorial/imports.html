Imports

Load a registered standard-library module.

KelpyShark's interpreter provides registered standard-library modules. Import a module by name, then access its functions and values through that module binding.

Importing a standard library module

Use import modulename at the top of your file. After that, call functions through the module name:

 use-math.ks
import math

print(math.sqrt(16))        # 4
print(math.floor(3.9))      # 3
print(math.ceil(3.1))       # 4
print(math.abs(-7))         # 7
print(math.pi)              # 3.141592653589793
Output
4
3
4
7
3.141592653589793

Importing multiple modules

List each import on its own line:

 multi-import.ks
import math
import strings
import io

name = strings.upper("kelpyshark")
print(name)                 # KELPYSHARK

root = math.sqrt(49)
print(root)                 # 7
Current limitation — The interpreter resolves registered standard-library modules. Importing a local .ks file or a package from libs/ is not implemented yet.

Available standard library modules

ModulePurpose
mathMaths functions and constants
stringsString manipulation utilities
ioFile reading and writing
jsonJSON parse and serialise
sysSystem info and exit
httpHTTP GET / POST requests

What you learned

  • import modulename loads a registered standard module
  • Access its items with module.function() or module.constant
  • KelpyShark ships with stdlib modules for maths, strings, files, JSON, and HTTP

Try it yourself

Write these steps in practice.ks, then run the file with kelpyshark run practice.ks.

  1. Import math and print the square root of 81.
  2. Import strings and print an uppercase version of a word.

Imports

Bring in standard library modules and other files.

A single file can only do so much. KelpyShark lets you import built-in modules and your own files so you can organise code across multiple files and reuse functionality without copying it.

Importing a standard library module

Use import modulename at the top of your file. After that, call functions through the module name:

 use-math.ks
import math

print(math.sqrt(16))        # 4
print(math.floor(3.9))      # 3
print(math.ceil(3.1))       # 4
print(math.abs(-7))         # 7
print(math.pi)              # 3.141592653589793
Output
4
3
4
7
3.141592653589793

Importing multiple modules

List each import on its own line:

 multi-import.ks
import math
import strings
import io

let name = strings.upper("kelpyshark")
print(name)                 # KELPYSHARK

let root = math.sqrt(49)
print(root)                 # 7

Importing your own files

Split your project into multiple .ks files and import them by relative path (without the .ks extension):

 utils.ks
# utils.ks — shared helpers
def greet(name) {
    return "Hello, {$name}!"
}

def double(n) {
    return n * 2
}
 main.ks
import utils

print(utils.greet("World"))     # Hello, World!
print(utils.double(21))         # 42
Output
Hello, World!
42
Tip — Put shared classes and helpers in their own files. Import them wherever you need them to keep each file focused and readable.

httpHTTP GET / POST requests

What you learned

  • import modulename loads a built-in or local module
  • Access its items with module.function() or module.constant
  • Import your own .ks files the same way
  • KelpyShark ships with stdlib modules for maths, strings, files, JSON, and HTTP

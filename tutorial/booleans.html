Booleans

True or false — the foundation of all logic in KelpyShark.

A boolean is a value that is either true or false. Booleans are the result of comparisons and logical expressions, and they drive all control flow in KelpyShark.

Boolean literals

 booleans.ks
let is_logged_in = true
let has_error    = false

print(is_logged_in)   # true
print(has_error)      # false

Booleans from comparisons

Any comparison expression produces a boolean:

 compare.ks
print(10 > 5)    # true
print(3 == 7)    # false
print(5 != 5)    # false
print(4 <= 4)    # true

Logical operators

Combine booleans with and, or, and not:

 logical.ks
let a = true
let b = false

print(a and b)   # false  (both must be true)
print(a or b)    # true   (at least one is true)
print(not a)     # false  (flips the value)

Truthiness

In conditions (like if), KelpyShark evaluates any value for its truthiness. The following values are considered falsy:

  • false
  • null
  • 0
  • "" (empty string)
  • [] (empty list)

Everything else is truthy.

 truthiness.ks
if 0 {
    print("won't print — 0 is falsy")
}

if "" {
    print("won't print — empty string is falsy")
}

if "hello" {
    print("will print — non-empty string is truthy")
}

if 42 {
    print("will print — non-zero number is truthy")
}

What you learned

  • Boolean values are true or false
  • Comparisons produce booleans
  • and, or, not combine booleans
  • Falsy values: false, null, 0, "", []
  • Everything else is truthy

Installation & Setup

Get KelpyShark running on your machine in minutes.

Requirements

KelpyShark runs on Windows, macOS, and Linux. No external runtime is required — the installer bundles everything you need.

Installing on Windows

Open PowerShell and run the one-line installer:

PowerShell
irm https://github.com/KelpyShark/main/raw/main/installer/install.ps1 | iex

This downloads the kelpyshark executable and adds it to your PATH automatically.

Installing on macOS & Linux

Shell
curl -fsSL https://github.com/KelpyShark/main/raw/main/installer/install.sh | bash

Verifying the installation

After installation, open a new terminal and run:

Terminal
kelpyshark --version
Output
KelpyShark 1.0.0

Running your first program

Create a file called hello.ks and write:

 hello.ks
print("Hello, World!")

Then run it:

Terminal
kelpyshark run hello.ks
Output
Hello, World!

Editor support

A VS Code extension is available that provides syntax highlighting and snippet support for .ks files. Search for "KelpyShark" in the VS Code Extensions panel to install it.

💡 Tip

KelpyShark files use the .ks extension.

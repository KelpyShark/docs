Installation & Setup

Install KelpyShark, check that it works, and run your first file.

Requirements

KelpyShark provides installers for Windows, macOS, and Linux. The interpreter is a standalone executable.

Installing on Windows

Open PowerShell and run the one-line installer:

PowerShell
irm https://github.com/KelpyShark/main/raw/main/installer/install.ps1 | iex

This downloads the kelpyshark executable and adds its install folder to your PATH. Open a new PowerShell window after installation.

Installing on macOS & Linux

Shell
curl -fsSL https://github.com/KelpyShark/main/raw/main/installer/install.sh | bash

Verifying the installation

After installation, open a new terminal and run:

Terminal
kelpyshark --version

The command prints the version of the installed CLI. If PowerShell or your shell cannot find kelpyshark, open a new terminal and check that the install folder is on your PATH.

Running your first program

Create a file called hello.ks and write:

 hello.ks
print("Hello, World!")

Then run it:

Terminal
kelpyshark run hello.ks
Output
Hello, World!

Choose an editor

Any text editor can create a KelpyShark program. Save the file with a .ks extension. Editor support is optional; the CLI runs the file directly.

💡 Tip

KelpyShark files use the .ks extension.

What you learned

  • Install the standalone KelpyShark CLI for your operating system
  • Check the installed command with kelpyshark --version
  • Run a source file with kelpyshark run hello.ks

Try it yourself

Use your editor and terminal to complete these steps:

  1. Create a file named hello.ks with one print statement.
  2. Run it with kelpyshark run hello.ks and change the printed text.

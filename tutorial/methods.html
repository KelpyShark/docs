Methods

Functions that belong to an object.

A method is a function defined inside a class. Methods can read and modify the object's attributes via self, and are called on an instance using dot notation.

Instance methods

Regular methods that operate on the object's data:

 methods.ks
class BankAccount {
    def new(owner, balance) {
        self.owner   = owner
        self.balance = balance
    }

    def deposit(amount) {
        self.balance += amount
        print("Deposited {$amount}. New balance: {$self.balance}")
    }

    def withdraw(amount) {
        if amount > self.balance {
            print("Insufficient funds!")
            return
        }
        self.balance -= amount
        print("Withdrew {$amount}. New balance: {$self.balance}")
    }

    def show_balance() {
        print("{$self.owner}'s balance: {$self.balance}")
    }
}

let acc = new BankAccount("Alice", 1000)
acc.show_balance()
acc.deposit(500)
acc.withdraw(200)
acc.withdraw(2000)
Output
Alice's balance: 1000
Deposited 500. New balance: 1500
Withdrew 200. New balance: 1300
Insufficient funds!

Methods calling other methods

Methods can call other methods on the same object using self:

 self-call.ks
class Rectangle {
    def new(width, height) {
        self.width  = width
        self.height = height
    }

    def area() {
        return self.width * self.height
    }

    def perimeter() {
        return 2 * (self.width + self.height)
    }

    def is_square() {
        return self.width == self.height
    }

    def describe() {
        print("{$self.width}x{$self.height} | Area: {$self.area()} | Square: {$self.is_square()}")
    }
}

let r = new Rectangle(4, 6)
r.describe()

let s = new Rectangle(5, 5)
s.describe()
Output
4x6 | Area: 24 | Square: false
5x5 | Area: 25 | Square: true

Static methods

A static method belongs to the class itself, not to any instance. It doesn't receive self and is called on the class name:

 static.ks
class MathUtils {
    static def max(a, b) {
        if a > b { return a }
        return b
    }

    static def clamp(value, min, max) {
        if value < min { return min }
        if value > max { return max }
        return value
    }
}

print(MathUtils.max(10, 20))         # 20
print(MathUtils.clamp(15, 0, 10))    # 10

What you learned

  • Methods are functions defined inside a class
  • They receive self automatically (the current instance)
  • Call them with instance.method()
  • Methods can call other methods via self.method()
  • static def creates a class-level method — no instance needed

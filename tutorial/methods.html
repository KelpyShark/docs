Methods

Functions that belong to an object.

A method is a function defined inside a class. Methods can read and modify the object's attributes via self, and are called on an instance using dot notation.

Instance methods

Regular methods that operate on the object's data:

 methods.ks
class BankAccount {
    def __init__(self, owner, balance) {
        self.owner   = owner
        self.balance = balance
    }

    def deposit(self, amount) {
        self.balance += amount
        print("Deposited {$amount}. New balance: {$self.balance}")
    }

    def withdraw(self, amount) {
        if amount > self.balance {
            print("Insufficient funds!")
            return
        }
        self.balance -= amount
        print("Withdrew {$amount}. New balance: {$self.balance}")
    }

    def show_balance(self) {
        print("{$self.owner}'s balance: {$self.balance}")
    }
}

 acc = new BankAccount("Alice", 1000)
acc.show_balance()
acc.deposit(500)
acc.withdraw(200)
acc.withdraw(2000)
Output
Alice's balance: 1000
Deposited 500. New balance: 1500
Withdrew 200. New balance: 1300
Insufficient funds!

Methods calling other methods

Methods can call other methods on the same object using self:

 self-call.ks
class Rectangle {
    def __init__(self, width, height) {
        self.width  = width
        self.height = height
    }

    def area(self) {
        return self.width * self.height
    }

    def perimeter(self) {
        return 2 * (self.width + self.height)
    }

    def is_square(self) {
        return self.width == self.height
    }

    def describe(self) {
        print("{$self.width}x{$self.height} | Area: {$self.area()} | Square: {$self.is_square()}")
    }
}

 r = new Rectangle(4, 6)
r.describe()

 s = new Rectangle(5, 5)
s.describe()
Output
4x6 | Area: 24 | Square: false
5x5 | Area: 25 | Square: true

Class-level helpers

Static methods are not supported yet. Define a top-level function when a helper does not need an instance:

 helper.ks
def clamp(value, lower, upper) {
    if value < lower { return lower }
    if value > upper { return upper }
    return value
}

print(clamp(15, 0, 10))

What you learned

  • Methods are functions defined inside a class
  • They receive self automatically (the current instance)
  • Call them with instance.method()
  • Methods can call other methods via self.method()
  • Use top-level functions for helpers that do not need an instance

Strings

Work with text in KelpyShark.

Creating strings

Write strings with double quotes:

 strings.ks
greeting = "Hello, World!"
print(greeting)

Escape sequences

Use backslash sequences to embed special characters inside strings:

SequenceMeaning
\nNewline
\tTab
\\Literal backslash
\"Double quote inside a double-quoted string
 escapes.ks
print("Line 1\nLine 2")
print("Column1\tColumn2")
print("She said \"hello\"")
Output
Line 1
Line 2
Column1	Column2
She said "hello"

String concatenation

Use + to join strings together:

 concat.ks
 first = "Kelpy"
 last  = "Shark"
 full  = first + last
print(full)   # KelpyShark

String length

Use the built-in len() function to get the number of characters in a string:

 length.ks
 word = "shark"
print(len(word))   # 5

Accessing individual characters

Index into a string with square brackets. Indices start at 0:

 indexing.ks
 s = "hello"
print(s[0])   # h
print(s[1])   # e
print(s[4])   # o

Extracting a substring

Use substring(start, end) to copy a range of characters (end is exclusive):

 substring.ks
s = "KelpyShark"
print(s.substring(0, 5))    # Kelpy
print(s.substring(5, 10))   # Shark

Looping over a string

A for loop visits each character one at a time:

 loop.ks
for ch in "hi!" {
    print(ch)
}
Output
h
i
!
Note

KelpyShark strings are immutable — once created, individual characters cannot be changed. To modify a string, create a new one.

What you learned

  • Strings use double quotes
  • Escape sequences: \n, \t, \\, \"
  • + concatenates strings
  • len(s) returns the string length
  • s[i] accesses a character and supports negative indices; s.substring(a, b) extracts a range

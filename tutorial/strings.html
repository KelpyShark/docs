Strings

Work with text in KelpyShark.

Creating strings

Strings can be written with double quotes or single quotes. Both behave identically:

 strings.ks
let a = "Hello, World!"
let b = 'Hello, World!'
print(a == b)   # true

Escape sequences

Use backslash sequences to embed special characters inside strings:

SequenceMeaning
\nNewline
\tTab
\\Literal backslash
\"Double quote inside a double-quoted string
\'Single quote inside a single-quoted string
 escapes.ks
print("Line 1\nLine 2")
print("Column1\tColumn2")
print("She said \"hello\"")
Output
Line 1
Line 2
Column1	Column2
She said "hello"

String concatenation

Use + to join strings together:

 concat.ks
let first = "Kelpy"
let last  = "Shark"
let full  = first + last
print(full)   # KelpyShark

String length

Use the built-in len() function to get the number of characters in a string:

 length.ks
let word = "shark"
print(len(word))   # 5

Accessing individual characters

Index into a string with square brackets. Indices start at 0:

 indexing.ks
let s = "hello"
print(s[0])   # h
print(s[1])   # e
print(s[4])   # o

Slicing

Extract a substring with [start:end] (end is exclusive):

 slice.ks
let s = "KelpyShark"
print(s[0:5])    # Kelpy
print(s[5:10])   # Shark

Looping over a string

A for loop visits each character one at a time:

 loop.ks
for ch in "hi!" {
    print(ch)
}
Output
h
i
!
📝 Note

KelpyShark strings are immutable — once created, individual characters cannot be changed. To modify a string, create a new one.

What you learned

  • Strings use double or single quotes
  • Escape sequences: \n, \t, \\, \"
  • + concatenates strings
  • len(s) returns the string length
  • s[i] accesses a character; s[a:b] slices

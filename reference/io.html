io Module

File reading, writing, and filesystem queries.

Usage
import io
FunctionReturnsDescription
io.read_file(path)stringRead entire file contents as a string. Throws if the file cannot be read.
io.write_file(path, content)nullWrite (overwrite) a file with content.
io.append_file(path, content)nullAppend content to a file, creating it if needed.
io.file_exists(path)booleanTrue if the path exists.
io.input(prompt)stringDisplay prompt and return a line of user input.

Examples

 io-demo.ks
import io

# Write a file
io.write_file("hello.txt", "Hello, KelpyShark!\n")

# Append to it
io.append_file("hello.txt", "Second line\n")

# Read it back
content = io.read_file("hello.txt")
print(content)

# File existence check
if io.file_exists("hello.txt") {
    print("File found!")
}

# User input
 name = io.input("Enter your name: ")
print("Welcome, {$name}!")
Warning — io.write_file() overwrites the file completely. Use io.append_file() to add content without replacing existing data.

Reading a CSV file

 csv.ks
import io
import strings

rows = strings.split(io.read_file("data.csv"), "\n")
for row in rows {
     cols = strings.split(row, ",")
    print("Name: {$cols[0]}  Score: {$cols[1]}")
}

Error handling with io

import io

try {
    data = io.read_file("missing.txt")
    print(data)
} catch (e) {
    print("File error: {$e}")
}

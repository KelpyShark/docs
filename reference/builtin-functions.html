Built-in Functions

Functions available in the interpreter without importing a module, plus the print statement.

print

The print statement writes a value to the console followed by a newline. Parentheses are optional.

Example
print("Hello")
print "KelpyShark"
print(42)
print(true)
Output
Hello
KelpyShark
42
true

len(value)

Returns the number of Unicode scalar values in a string, or the number of items in a list or dictionary.

Example
print(len("hello"))       # 5
print(len([1, 2, 3]))     # 3

type(value)

Returns a string describing the type of value.

Example
print(type(42))           # number
print(type("hi"))         # string
print(type(true))         # boolean
print(type(null))         # null
print(type([]))           # list
print(type({}))           # dict

str(value)

Converts value to its string representation.

Example
n = 3.14
s = str(n)
print(s + " is pi")       # 3.14 is pi

num(value)

Converts a number, numeric string, or boolean to a number. Throws an error when the value cannot be converted.

Example
x = num("42")
print(x + 1)              # 43

y = num("3.14")
print(y * 2)              # 6.28

range(stop) / range(start, stop) / range(start, stop, step)

Returns a list of numbers. Useful with for loops.

Example
print(range(5))           # [0, 1, 2, 3, 4]
print(range(2, 6))        # [2, 3, 4, 5]
print(range(0, 10, 2))    # [0, 2, 4, 6, 8]

for i in range(3) {
    print(i)
}

push(list, value)

Appends value to the end of list. Modifies the list in place.

Example
nums = [1, 2]
push(nums, 3)
print(nums)               # [1, 2, 3]

To remove and return a list's last item, call list.pop().

Number conversions

int truncates toward zero. float and num preserve decimal values.

Example
print(int(3.8))       # 3
print(int(-3.8))      # -3
print(float("3.14"))  # 3.14
print(num(true))      # 1

input(prompt)

Displays a prompt and returns the line entered by the user as a string.

Example
name = input("Your name: ")
print("Hello, {$name}!")

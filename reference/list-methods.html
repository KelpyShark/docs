List Methods

Methods and functions for working with lists.

Lists are ordered, mutable collections. Use the built-in functions below or call supported methods on the list.

Built-in list functions

FunctionDescription
push(list, item)Append item to the end of list
len(list)Number of items in the list

List dot-methods

MethodReturnsDescription
.length()numberNumber of items (same as len())
.append(item) / .push(item)listAppend an item in place
.pop()valueRemove and return the last item; errors on an empty list
.contains(item)booleanTrue if item is in the list
.reverse()listReverse the list in place
.sort()listSort numbers or strings in place
.join(sep)stringJoin all items into a string separated by sep
.first() / .last()valueReturn the first or last item

Examples

 list-methods.ks
 fruits = ["apple", "banana", "cherry"]

# Length
print(len(fruits))               # 3
print(fruits.length())           # 3

# Contains
print(fruits.contains("banana")) # true

# push / pop
push(fruits, "date")
print(fruits)                    # ["apple", "banana", "cherry", "date"]
 removed = fruits.pop()
print(removed)                   # date

# Reverse
fruits.reverse()
print(fruits)                    # ["cherry", "banana", "apple"]

# Join
print(fruits.join(", "))         # cherry, banana, apple

# Indexing
print(fruits[0])                 # cherry
fruits[1] = "blueberry"
print(fruits)                    # ["cherry", "blueberry", "apple"]

Iterating over a list

 iterate.ks
 scores = [88, 95, 72, 100, 61]

# Simple iteration
for score in scores {
    print(score)
}

# With index (using range)
for i in range(len(scores)) {
    print("{$i}: {$scores[i]}")
}

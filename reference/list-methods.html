List Methods

Methods and functions for working with lists.

Lists are ordered, mutable collections. Many operations are available as built-in functions and as dot-notation methods on the list itself.

Built-in list functions

FunctionDescription
push(list, item)Append item to the end of list
pop(list)Remove and return the last item
len(list)Number of items in the list

List dot-methods

MethodReturnsDescription
.length()numberNumber of items (same as len())
.contains(item)booleanTrue if item is in the list
.index_of(item)numberIndex of first occurrence, or -1
.reverse()listA new list with items in reverse order
.slice(start, end)listSub-list from start to end (exclusive)
.join(sep)stringJoin all items into a string separated by sep

Examples

 list-methods.ks
let fruits = ["apple", "banana", "cherry"]

# Length
print(len(fruits))               # 3
print(fruits.length())           # 3

# Contains / index
print(fruits.contains("banana")) # true
print(fruits.index_of("cherry")) # 2

# push / pop
push(fruits, "date")
print(fruits)                    # ["apple", "banana", "cherry", "date"]
let removed = pop(fruits)
print(removed)                   # date

# Slice
print(fruits.slice(1, 3))        # ["banana", "cherry"]

# Reverse
print(fruits.reverse())          # ["cherry", "banana", "apple"]

# Join
print(fruits.join(", "))         # apple, banana, cherry

# Indexing
print(fruits[0])                 # apple
fruits[1] = "blueberry"
print(fruits)                    # ["apple", "blueberry", "cherry"]

Iterating over a list

 iterate.ks
let scores = [88, 95, 72, 100, 61]

# Simple iteration
for score in scores {
    print(score)
}

# With index (using range)
for i in range(len(scores)) {
    print("{$i}: {$scores[i]}")
}

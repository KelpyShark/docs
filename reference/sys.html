sys Module

System information and runtime control.

Usage
import sys

Properties

PropertyTypeDescription
sys.platformstring"windows", "linux", or "macos"
sys.versionstringKelpyShark version, e.g. "1.2.0"
sys.argslistCommand-line arguments passed to the script
sys.envdictionaryEnvironment variables as a dictionary

Functions

FunctionReturnsDescription
sys.exit(code)—Terminate the program with exit code code (0 = success)
sys.sleep(ms)nullPause execution for ms milliseconds
sys.time()numberCurrent Unix timestamp in seconds

Examples

 sys-demo.ks
import sys

# Platform detection
if sys.platform == "windows" {
    print("Running on Windows")
} else {
    print("Running on {$sys.platform}")
}

# Version info
print("KelpyShark {$sys.version}")

# Command-line args
# $ kelpyshark run script.ks hello world
print(sys.args)       # ["hello", "world"]

# Environment variables
let home = sys.env["HOME"]
print("Home: {$home}")

# Timing
let start = sys.time()
sys.sleep(500)
let elapsed = sys.time() - start
print("Elapsed: ~{$elapsed}s")

Argument handling pattern

 cli-args.ks
import sys

if len(sys.args) < 1 {
    print("Usage: kelpyshark run script.ks <name>")
    sys.exit(1)
}

let name = sys.args[0]
print("Hello, {$name}!")

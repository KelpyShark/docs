sys Module

System information and runtime control.

Usage
import sys

Functions

FunctionReturnsDescription
sys.platform()stringOperating system name.
sys.cwd()stringCurrent working directory.
sys.args()listArguments passed after -- to kelpyshark run.
sys.env(name)string or nullRead one environment variable; returns null if it is unset.
sys.clock()numberCurrent Unix timestamp in seconds.
sys.sleep(seconds)nullPause execution for the given number of seconds.
sys.exit(code)—Terminate the process with the given exit code.

Examples

 sys-demo.ks
import sys

# Platform and working directory
print(sys.platform())
print(sys.cwd())

# Script arguments and environment
print(sys.args())
home = sys.env("HOME")
print(home)

# Timing
 timestamp = sys.clock()
sys.sleep(0.1)
print(timestamp)

Argument handling pattern

 cli-args.ks
import sys

args = sys.args()
print(args)  # values after `--` in the run command

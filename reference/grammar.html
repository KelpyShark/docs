Grammar

Formal syntax rules for the KelpyShark language.

This page describes the formal grammar of KelpyShark in an extended BNF notation. Terminals are shown in "quotes", non-terminals in italic, and optional parts in [brackets].

Program structure

Grammar
program     = statement*

statement   = let_stmt
            | assign_stmt
            | expr_stmt
            | print_stmt
            | if_stmt
            | while_stmt
            | for_stmt
            | def_stmt
            | class_stmt
            | return_stmt
            | import_stmt
            | try_stmt
            | throw_stmt
            | break_stmt
            | continue_stmt

Statements

Grammar
let_stmt    = "let" IDENT "=" expr

assign_stmt = lvalue ("=" | "+=" | "-=" | "*=" | "/=" | "%=") expr

lvalue      = IDENT
            | expr "[" expr "]"
            | expr "." IDENT

print_stmt  = "print" "(" expr ")"

if_stmt     = "if" expr block
              ("elif" expr block)*
              ["else" block]

while_stmt  = "while" expr block

for_stmt    = "for" IDENT "in" expr block

def_stmt    = ["static"] "def" IDENT "(" param_list ")" block

param_list  = (IDENT ["=" expr] ("," IDENT ["=" expr])*)?

class_stmt  = "class" IDENT ["(" IDENT ")"] "{" def_stmt* "}"

return_stmt = "return" [expr]

import_stmt = "import" IDENT

try_stmt    = "try" block "catch" "(" IDENT ")" block

throw_stmt  = "throw" expr

break_stmt  = "break"
continue_stmt = "continue"

block       = "{" statement* "}"

Expressions

Grammar
expr        = or_expr

or_expr     = and_expr ("or" and_expr)*

and_expr    = not_expr ("and" not_expr)*

not_expr    = "not" not_expr
            | cmp_expr

cmp_expr    = add_expr (("==" | "!=" | "<" | ">" | "<=" | ">=") add_expr)*

add_expr    = mul_expr (("+" | "-") mul_expr)*

mul_expr    = pow_expr (("*" | "/" | "%") pow_expr)*

pow_expr    = unary_expr ("^" pow_expr)?

unary_expr  = "-" unary_expr
            | postfix_expr

postfix_expr = primary
             | postfix_expr "." IDENT
             | postfix_expr "." IDENT "(" arg_list ")"
             | postfix_expr "[" expr "]"
             | postfix_expr "(" arg_list ")"

primary     = NUMBER
            | STRING
            | "true" | "false" | "null"
            | IDENT
            | "new" IDENT "(" arg_list ")"
            | "[" (expr ("," expr)*)? "]"
            | "{" (STRING ":" expr ("," STRING ":" expr)*)? "}"
            | "(" expr ")"

arg_list    = (expr ("," expr)*)?

Tokens

Grammar
IDENT   = [a-zA-Z_][a-zA-Z0-9_]*
NUMBER  = [0-9]+ ("." [0-9]+)?
STRING  = '"' char* '"'
          (char may be any UTF-8 character; "{$" IDENT "}" is interpolation)
COMMENT = "#" ... end-of-line  (ignored by the parser)
Note — KelpyShark is whitespace-insensitive except for string literals. Newlines are not statement terminators; semicolons are not required or used.

Grammar

Formal syntax rules for the KelpyShark language.

This page describes the formal grammar of KelpyShark in an extended BNF notation. Terminals are shown in "quotes", non-terminals in italic, and optional parts in [brackets].

Program structure

Grammar
program     = statement*

statement   = assign_stmt
            | expr_stmt
            | print_stmt
            | if_stmt
            | while_stmt
            | for_stmt
            | def_stmt
            | class_stmt
            | return_stmt
            | import_stmt
            | try_stmt
            | throw_stmt
            | break_stmt
            | continue_stmt

Statements

Grammar
assign_stmt = IDENT ("=" | "+=" | "-=" | "*=" | "/=") expr
            | member_or_index "=" expr

member_or_index = expr "[" expr "]"
                | expr "." IDENT

expr_stmt   = expr

print_stmt  = "print" expr

if_stmt     = if_braced | if_colon
if_braced   = "if" expr block
              ("elif" expr block)*
              ["else" block]

while_stmt  = "while" expr block

for_stmt    = "for" IDENT "in" expr block

def_stmt    = "def" IDENT "(" param_list ")" block

param_list  = (IDENT ("," IDENT)*)?

class_stmt  = "class" IDENT block

return_stmt = "return" [expr]

import_stmt = "import" (IDENT ("." IDENT)*)

try_stmt    = try_braced | try_colon

try_braced  = "try" block "catch" "(" IDENT ")" block

throw_stmt  = "throw" expr

break_stmt  = "break"
continue_stmt = "continue"

block       = "{" statement* "}"
            | ":" statement* "end"

if_colon    = "if" expr ":" statement*
              ("elif" expr ":" statement*)*
              ["else" ":" statement*] "end"

try_colon   = "try" ":" statement*
              "catch" "(" IDENT ")" ":" statement* "end"

Expressions

Grammar
expr        = or_expr

or_expr     = and_expr ("or" and_expr)*

and_expr    = not_expr ("and" not_expr)*

not_expr    = "not" not_expr
            | cmp_expr

cmp_expr    = add_expr (("==" | "!=" | "<" | ">" | "<=" | ">=") add_expr)*

add_expr    = mul_expr (("+" | "-") mul_expr)*

mul_expr    = unary_expr (("*" | "/" | "%") unary_expr)*

unary_expr  = "-" unary_expr
            | postfix_expr

postfix_expr = primary
             | postfix_expr "." IDENT
             | postfix_expr "." IDENT "(" arg_list ")"
             | postfix_expr "[" expr "]"
             | postfix_expr "(" arg_list ")"

primary     = NUMBER
            | STRING
            | "true" | "false" | "null"
            | IDENT
            | "new" IDENT "(" arg_list ")"
            | "[" (expr ("," expr)*)? "]"
            | "{" (expr ":" expr ("," expr ":" expr)*)? "}"
            | "(" expr ")"

arg_list    = (expr ("," expr)*)?

Tokens

Grammar
IDENT   = [a-zA-Z_][a-zA-Z0-9_]*
NUMBER  = [0-9]+ ("." [0-9]+)?
STRING  = '"' char* '"'
          ("{$" IDENT "}" is variable interpolation)
COMMENT = "#" ... end-of-line
BLOCK_COMMENT = "###" ... "###"
Note — Indentation is optional and has no effect on program meaning. Newlines separate statements. Blocks use braces or a colon followed by end; semicolons are not used. This grammar has no declaration keyword, default parameters, static methods, or class inheritance. Compound assignment applies only to variable names.

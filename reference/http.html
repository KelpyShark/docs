http Module

Make HTTP requests to web APIs and servers.

Usage
import http

Functions

FunctionReturnsDescription
http.get(url)stringReturn the response body for an HTTP GET request.
http.get_status(url)numberReturn the GET response status code.
http.post(url, body)stringPOST a text body and return the response body.
http.post_json(url, body)stringPOST a JSON body with an application/json content type.

These calls are synchronous. The current API does not expose response headers or custom request headers. HTTP error statuses from get and post are reported as runtime errors; use get_status when you need a status code.

GET request

 get.ks
import http
import json

body = http.get("https://jsonplaceholder.typicode.com/todos/1")
data = json.decode(body)
print(data["title"])
print(http.get_status("https://jsonplaceholder.typicode.com/todos/1"))

POST request

 post.ks
import http
import json

 payload = json.encode({
    "title": "My new post",
    "body": "Hello from KelpyShark",
    "userId": 1
})

 response = http.post_json("https://jsonplaceholder.typicode.com/posts", payload)
created = json.decode(response)
print(created["id"])
Note — HTTP support is limited to GET, POST, status lookup, and JSON POST. Custom headers and authenticated GET requests are not supported by the current API.

Types

All data types in KelpyShark.

KelpyShark is dynamically typed — variables don't have a fixed type; they hold whatever value is assigned to them. Use type(value) to inspect the type at runtime.

Type name type() returns Literal examples Notes
Number "number" 42, 3.14, -7 Integers and floats share one type
String "string" "hello", "it's {$x}" UTF-8; supports {$…} interpolation
Boolean "boolean" true, false Result of comparisons and logic expressions
Null "null" null Absence of a value; functions without return return null
List "list" [1, 2, 3], [] Ordered, mutable, mixed-type
Dictionary "dict" {"a": 1}, {} String keys, any values
Instance "ClassName" new Dog("Rex") type() returns the class name
Function "function" def f() { } type() returns "function" for user functions and "native_function" for built-ins

Number

 types.ks
 i = 100
 f = 3.14
print(type(i))    # number
print(type(f))    # number

String

 s = "hello"
print(type(s))    # string
print(len(s))     # 5

Boolean

 b = 5 > 3
print(type(b))    # boolean
print(b)          # true

Null

 n = null
print(type(n))    # null
print(n == null)  # true

List

 lst = [1, "two", true]
print(type(lst))    # list
print(lst[1])       # two

Dictionary

 d = {"name": "Alice", "age": 30}
print(type(d))         # dict
print(d["name"])       # Alice

Instance

Classes are values too: type(MyClass) returns "class". An instance reports its class name.

class Cat {}
 c = new Cat()
print(type(c))    # Cat

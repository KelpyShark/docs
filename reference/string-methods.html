String Methods

Methods available on every string value.

These methods are called directly on a string variable using dot notation: myString.method(). They never modify the original string; they return a new one.

MethodReturnsDescription
.upper()stringUppercase version
.lower()stringLowercase version
.trim()stringRemoves leading and trailing whitespace
.length()numberNumber of characters (same as len())
.contains(sub)booleanTrue if sub appears in the string
.starts_with(prefix)booleanTrue if string begins with prefix
.ends_with(suffix)booleanTrue if string ends with suffix
.replace(old, new)stringReplaces all occurrences of old with new
.split(sep)listSplits on sep; returns list of substrings
.index_of(sub)numberIndex of first occurrence, or -1 if not found
.slice(start, end)stringSubstring from start (inclusive) to end (exclusive)
.repeat(n)stringString repeated n times
.reverse()stringCharacters in reverse order

Examples

 string-methods.ks
let s = "  Hello, World!  "

print(s.trim())                    # Hello, World!
print(s.trim().upper())            # HELLO, WORLD!
print(s.trim().lower())            # hello, world!
print(s.trim().length())           # 13
print(s.trim().contains("World"))  # true
print(s.trim().starts_with("He")) # true
print(s.trim().ends_with("!"))    # true
print(s.trim().replace("World", "KelpyShark"))  # Hello, KelpyShark!

let csv = "apple,banana,cherry"
print(csv.split(","))              # ["apple", "banana", "cherry"]

let word = "abcdef"
print(word.slice(2, 5))           # cde
print(word.index_of("cd"))        # 2
print(word.reverse())             # fedcba
print("ha".repeat(3))             # hahaha
Note — You can also use the strings stdlib module for the same operations as free functions: strings.upper(s), strings.split(s, sep), etc.

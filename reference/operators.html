Precedence

From highest to lowest precedence:

  1. ^ (power, right-associative)
  2. Unary - and not
  3. * / %
  4. + -
  5. < > <= >=
  6. == !=
  7. and
  8. or
  9. Assignment (= += …)
Tip — Use parentheses to make precedence explicit and improve readability. (a + b) * c is clearer than relying on operator precedence.

strings Module

String manipulation as free functions.

Usage
import strings

The strings module mirrors the string dot-methods but as standalone functions. Useful when passing string operations as callbacks or building pipelines.

FunctionReturnsDescription
strings.upper(s)stringUppercase version of s
strings.lower(s)stringLowercase version of s
strings.trim(s)stringRemove leading/trailing whitespace
strings.replace(s, old, new)stringReplace all occurrences of old with new
strings.split(s, sep)listSplit s on separator sep
strings.join(sep, list)stringJoin list items with sep
strings.contains(s, sub)booleanTrue if sub appears in s
strings.starts_with(s, prefix)booleanTrue if s starts with prefix
strings.ends_with(s, suffix)booleanTrue if s ends with suffix
strings.reverse(s)stringReverse the characters of s
strings.char_at(s, index)stringReturn one character by zero-based index
strings.substring(s, start, end)stringReturn characters from start to exclusive end

Examples

 strings-demo.ks
import strings

words = ["the", "quick", "brown", "fox"]
print(strings.join(" ", words))
# the quick brown fox

# CSV parsing
csv = "Alice,30,Engineer"
parts = strings.split(csv, ",")
print(parts[0])    # Alice
print(parts[1])    # 30

# Table formatting with padding
print(strings.substring("KelpyShark", 0, 5))  # Kelpy
print(strings.char_at("Kelpy", 0))             # K

Package Manager

Install, publish, and manage KelpyShark packages.

What is a package?

A KelpyShark package is a directory of .ks files with a ks.toml manifest. Packages can be shared on the official registry and installed with a single command.

The manifest — ks.toml

ks.toml
[package]
name    = "my-package"
version = "1.0.0"
author  = "Your Name"
description = "A short description"

[dependencies]
some-lib = "^2.1"
FieldRequiredDescription
nameYesPackage name (lowercase, hyphens allowed)
versionYesSemantic version string
authorNoAuthor or organisation name
descriptionNoOne-line description shown in search results

Installing a package

Shell
kelpyshark pkg install colors

The package is downloaded and placed in .ks_modules/ in the current directory. Import it by name:

 main.ks
import colors

print(colors.red("Error!"))
print(colors.green("Success!"))

Version constraints

SyntaxMeaning
"1.2.3"Exact version
"^1.2.3"Compatible with 1.2.3 (same major)
"~1.2.3"Compatible with 1.2.x (same major+minor)
">=1.0"At least version 1.0

Publishing a package

  1. Make sure your ks.toml is complete.
  2. Run kelpyshark pkg publish.
  3. You'll be prompted for your registry credentials.
  4. The package is uploaded and immediately available for others to install.
Shell
kelpyshark pkg publish

Updating packages

Shell
kelpyshark pkg update            # update all packages
kelpyshark pkg update colors     # update one specific package

Removing a package

Shell
kelpyshark pkg remove colors

Searching the registry

Shell
kelpyshark pkg search http

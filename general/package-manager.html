Package Manager

Install, publish, and manage KelpyShark packages.

What is a package?

A KelpyShark package is a project directory with a kelpy.toml manifest and source files. Published packages are stored in a local registry at ~/.kelpyshark/registry/ (or the Windows user profile directory); there is no public registry connection.

The manifest — kelpy.toml

kelpy.toml
[package]
name    = "my-package"
version = "1.0.0"
description = "A short description"

[dependencies]
some-lib = "2.1.0"
FieldRequiredDescription
nameYesLetters, digits, underscores, and hyphens; must start with a letter or digit
versionNoExact semantic version; defaults to 0.1.0
descriptionNoPackage description
[dependencies]NoPackage names mapped to exact semantic versions

Installing a package

Shell
kelpyshark install colors
kelpyshark install

The named form selects the highest version in the local registry, records that exact version in kelpy.toml, and installs its dependency graph under libs/. The unnamed form installs the exact versions in the project manifest and writes kelpy.lock.

Only registered standard-library modules can currently be imported by KelpyShark code. Importing source files from libs/ is not implemented, so installed packages are not yet usable from a script.

Dependency versions

SyntaxMeaning
"1.2.3"Exact semantic version (the only supported form)
"^1.2.3", "~1.2.3", ">=1.2.3"Rejected; version ranges are not implemented

Publishing a package

  1. Make sure the project contains a valid kelpy.toml.
  2. Run kelpyshark publish from the project directory.
  3. The package is copied into your local registry and can be installed by projects on this machine.
Shell
kelpyshark publish

Updating packages

Shell
kelpyshark update

Updates select the latest local-registry version for each direct dependency, resolve the complete dependency graph, and replace installed package copies when needed.

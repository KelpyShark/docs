CLI Reference

All commands provided by the kelpyshark binary.

Synopsis

Shell
kelpyshark <command> [options] [args]
kshark     <command> [options] [args]
ks         <command> [options] [args]

All three names are identical — use whichever you prefer.

Commands

run

Interpret and run a .ks file.

Shell
kelpyshark run <file.ks> [-- arg1 arg2 ...]

Arguments after -- are available in the script as sys.args.

Examples
kelpyshark run hello.ks
kelpyshark run script.ks -- Alice 42

build

Compile a .ks file to a native executable.

Shell
kelpyshark build <file.ks> [-o output]
FlagDescription
-o <name>Name of the output binary (default: file name without .ks)
--releaseEnable optimisations

check

Parse and type-check a file without running it.

Shell
kelpyshark check <file.ks>

fmt

Auto-format a .ks file in place.

Shell
kelpyshark fmt <file.ks>
kelpyshark fmt .          # format all .ks files in the current directory

new

Create a new KelpyShark project with a starter layout.

Shell
kelpyshark new <project-name>

Creates:

Generated structure
project-name/
  main.ks
  ks.toml

pkg — Package manager

Sub-commands for the built-in package manager:

CommandDescription
kelpyshark pkg install <name>Install a package
kelpyshark pkg remove <name>Uninstall a package
kelpyshark pkg listList installed packages
kelpyshark pkg updateUpdate all installed packages
kelpyshark pkg publishPublish the current package to the registry
kelpyshark pkg search <query>Search the registry

version

Print the installed KelpyShark version.

Shell
kelpyshark version
Output
kelpyshark 1.2.0

help

Show help for any command.

Shell
kelpyshark help
kelpyshark help run

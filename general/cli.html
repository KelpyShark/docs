CLI Reference

All commands provided by the kelpyshark binary.

Synopsis

Shell
kelpyshark <command> [options] [args]
kshark     <command> [options] [args]
ks         <command> [options] [args]

All three names are identical — use whichever you prefer.

Commands

run

Interpret and run a .ks file. Optional script arguments follow -- and are returned by sys.args().

Shell
kelpyshark run main.ks
kelpyshark run main.ks -- Alice 42

repl

Start the interactive interpreter.

Shell
kelpyshark repl

build / compile

Parse and semantically check a file, then generate source code for the selected target. This command does not compile the generated source to an executable.

Shell
kelpyshark build main.ks --target js --output main.js
kelpyshark build main.ks --target java
OptionDescription
--targetc, js, java, or cs; defaults to c.
-o, --outputOutput source path. By default, writes beside the input using the target extension.

new

Create a new project. The command stops if the destination already exists.

Shell
kelpyshark new my-project
my-project/
  kelpy.toml
  src/main.ks
  libs/

Package commands

CommandDescription
kelpyshark install [name]Install one named package, or install project dependencies when no name is supplied.
kelpyshark publishPublish the current project.
kelpyshark updateUpdate project dependencies.

Help and version

Use --help for command usage and --version to print the installed version.

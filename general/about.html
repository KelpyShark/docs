About KelpyShark

What it is, why it exists, and how it works.

What is KelpyShark?

KelpyShark is a dynamically typed programming language. The interpreter runs .ks programs directly. The project also includes code generators that translate supported programs into C, JavaScript, Java, or C# source.

Design goals

  • Beginner-friendly — clear error messages, simple syntax, no hidden complexity
  • Readable — code should read like plain English where possible
  • Batteries-included — a standard library covering maths, strings, files, JSON, HTTP, and system access
  • Portable — installers are provided for Windows, Linux, and macOS
  • Small setup — the interpreter is distributed as a standalone executable

How it works

Running and building a KelpyShark file share the first two stages. The build command also checks the program before it generates target source:

  1. Lexer — source text is scanned into a stream of tokens (numbers, strings, keywords, identifiers, operators, …)
  2. Parser — the token stream is structured into an Abstract Syntax Tree (AST)
  3. Run — the interpreter walks the AST and evaluates each node, producing output
  4. Build — semantic checks run before a target-specific code generator writes source code

kelpyshark build generates source files; it does not invoke a C, Java, JavaScript, or C# compiler. Each generator supports only part of the language. Use the interpreter for the most complete behavior.

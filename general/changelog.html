Changelog

What's new in each version of KelpyShark.

Current workspace — v0.2.0

  • Indentation-independent blocks using braces or a colon followed by end.
  • Interpreter support for functions, classes, mutable collections, exceptions, and registered standard-library modules.
  • Checked source generation for C, JavaScript, Java, and C# language subsets.
  • CLI commands for running, building, project creation, and package operations.
  • Package manifest validation, registry resolution, installation, publishing, and dependency updates.

Not implemented in this version

  • Indentation-significant Python-style blocks, inheritance, static methods, and default function parameters.
  • Importing local .ks files and packages from programs.
  • Full interpreter parity across all code-generation targets.

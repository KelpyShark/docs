Changelog

What's new in each version of KelpyShark.

v1.2.0

  • Added http standard library module (GET, POST, PUT, DELETE)
  • Added Java code generation backend (--target java)
  • Added C# code generation backend (--target csharp)
  • Package manager: pkg publish and pkg update commands
  • Compound assignment operators: +=, -=, *=, /=, %=
  • String method .repeat(n)
  • Improved error messages with source locations
  • Significant interpreter performance improvements

v1.1.0

  • Classes and object-oriented programming (class, new, self)
  • Inheritance (class Child(Parent)) and super()
  • Static methods (static def)
  • Default parameter values in functions
  • json standard library module
  • sys standard library module
  • VS Code syntax highlighting extension
  • Package manager initial release
  • for item in list loop syntax
  • break and continue

v1.0.0

  • Initial release
  • Variables, numbers, strings, booleans, null
  • Lists and dictionaries
  • Functions (def) and return values
  • If / elif / else
  • While loops
  • Try / catch / throw error handling
  • Imports (import modulename)
  • math, strings, io standard library modules
  • Built-in functions: print, len, type, str, num, range, push, pop
  • String interpolation with {$variable}
  • kelpyshark run and kelpyshark build CLI commands
  • Windows, Linux, and macOS support

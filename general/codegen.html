Code Generation

Cross-compile KelpyShark to Java and C#.

In addition to running KelpyShark files directly with the interpreter, the compiler can transpile your code to other languages. This lets you deploy KelpyShark logic in Java or .NET environments without rewriting it by hand.

Java codegen

The Java backend emits Java 11-compatible source code. Each KelpyShark file becomes a Java class. The output can be compiled with any standard Java compiler (javac).

Shell
kelpyshark build --target java hello.ks -o Hello.java
javac Hello.java
java Hello

C# codegen

The C# backend emits .NET 6-compatible source code. Classes, methods, and control flow all map cleanly to C# equivalents.

Shell
kelpyshark build --target csharp hello.ks -o Hello.cs
dotnet script Hello.cs

Limitations

  • Dynamic features (e.g. adding attributes to instances at runtime) may produce verbose generated code
  • Standard library modules are not automatically translated — stdlib calls are emitted as comments if no equivalent exists
  • Code generation targets stable, idiomatic output rather than trying to optimise
Tip — Use code generation when you need to hand off KelpyShark business logic to a Java or .NET team. The generated source is readable and can be refined manually after transpilation.

FAQ

Frequently asked questions about KelpyShark.

Do I need to install a separate runtime?

No. KelpyShark is distributed as a single self-contained binary. Download it, put it on your PATH, and you're ready to go. See the Setup page for instructions.

Is KelpyShark statically or dynamically typed?

Dynamically typed. Variables hold values of any type, and the type can change during the lifetime of the variable. Use type() to inspect the type at runtime if needed.

Do I need semicolons?

No. KelpyShark does not use semicolons as statement terminators. Just write each statement on its own line (or on consecutive lines — the language is whitespace-insensitive outside of string literals).

How do I read input from the user?

Use io.input(prompt):

import io

let name = io.input("What is your name? ")
print("Hello, {$name}!")

Can I use KelpyShark for web development?

You can build HTTP-based scripts (calling APIs, processing JSON, serving simple responses). A full web framework is not yet part of the standard library, but packages in the registry may provide one.

How do I share code between files?

Put shared code in a .ks file and use import: 

import utils          # imports utils.ks from the same directory

utils.my_function()

Why does type() return a string instead of a type object?

Simplicity. Returning a plain string means you can compare types with == without learning a separate type system. type(x) == "number" is immediately readable.

What happens if I divide by zero?

KelpyShark raises a runtime error: Division by zero. Catch it with try / catch if you need to handle that case.

Can I compile KelpyShark to Java or C#?

Yes. See the Code Generation page for details.

Where can I get help?

Open an issue on the GitHub repository, or check the Tutorial and Reference sections of these docs first.
